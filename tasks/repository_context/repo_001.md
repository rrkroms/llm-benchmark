# REPO-001 — Long-Context Repository Understanding

Use the repository fixture at `tasks/repository_context/fixture/`.

## Task
Analyze the repository and answer:

1. What is the application entry point?
2. What is the main execution path for creating an order?
3. Where is configuration loaded?
4. Which external dependencies are used?
5. Which tests cover order creation?
6. Where are exceptions created, transformed, logged, and returned?
7. What is the transaction boundary?
8. What files would you change to fix the supplied bug described in `docs/BUG.md`?
9. What files should remain unchanged?
10. Describe the architecture using concrete file paths and symbols.

## Evidence rule
Every important claim must cite a file path and a symbol/function/class. Filename-only reasoning receives reduced credit.
