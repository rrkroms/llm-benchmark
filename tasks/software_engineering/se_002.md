# SE-002 — Silent Failure Bug

**Parameter:** Software Engineering / Coding

Given:

```python
def process_items(items, transform):
    result = []
    for item in items:
        try:
            result.append(transform(item))
        except Exception:
            pass
    return result
```

## Task
Identify the defects and replace the implementation with a production-quality version.

Your design must address:

- accidental suppression of unexpected failures
- predictable handling of per-item failures
- input validation
- observability/debuggability
- caller-friendly semantics
- unit testing

Do not silently change the contract without explaining it. Provide tests for success, one-item failure, all-item failure, invalid input, and an unexpected exception.

## Evaluator focus
Engineering judgment, error semantics, backward-compatibility reasoning, and test quality.
