# SE-001 — Retry With Exponential Backoff

**Parameter:** Software Engineering / Coding

## Task
Implement `retry_with_backoff(operation, max_retries, base_delay)` in Python.

Requirements:

- `operation` is a zero-argument callable.
- Call it once initially.
- On failure, retry at most `max_retries` additional times.
- Delay before retry `i` is `base_delay * (2 ** (i-1))`, where `i=1` is the first retry.
- Return the successful result immediately.
- Raise the final exception after all allowed attempts fail.
- Reject negative `max_retries` and negative `base_delay`.
- Avoid sleeping when no retry will occur.
- Make the implementation testable without forcing real wall-clock delays.

## Deliverable
Provide implementation plus unit tests for:

1. Immediate success
2. Success after one retry
3. Exhausted retries
4. Zero retries
5. Negative arguments
6. Correct backoff sequence
7. Preservation of the final exception

## Evaluator focus
Correct retry count, edge cases, exception semantics, testability, and code quality.
