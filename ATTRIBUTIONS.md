# Attribution and Provenance

## Original project contents

The benchmark prompts, benchmark task files, scoring rubric, answer key, evaluator templates, result schemas, runner/scorer scripts, repository fixture, and included benchmark assets in this repository were created specifically for this benchmark pack.

No source files from SWE-bench, Berkeley Function Calling Leaderboard (BFCL), LongBench, or another external benchmark repository were copied into this project.

## Methodology inspiration

This project uses evaluation ideas that are common in LLM benchmarking, including execution-based software-engineering evaluation, repository-level tasks, function/tool-use evaluation, multimodal testing, and structured-output validation. These are methodological inspirations, not copied source code.

Relevant public projects/papers that informed the benchmark design include:

- SWE-bench — https://www.swebench.com/
- Berkeley Function Calling Leaderboard (BFCL) — https://gorilla.cs.berkeley.edu/leaderboard.html
- LongBench — https://github.com/THUDM/LongBench

These projects retain their own copyrights and licenses. This repository does not redistribute their source code, task datasets, or benchmark assets.

## Generated/local assets

The small repository fixture and vision test image are included as benchmark-specific test assets created for this project. They are not sourced from an external repository.
